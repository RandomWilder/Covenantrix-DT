# Feature 0050: Text Selection and Copy in Chat Messages

## Description
Enable users to select text from chat messages using mouse selection and copy it using standard keyboard shortcuts (Ctrl+C) or right-click context menu. This feature will allow partial text selection from any message (user or assistant) while maintaining the existing "copy entire message" button functionality.

## Technical Requirements

### Problem
Currently, text selection is globally disabled via CSS (`-webkit-user-select: none`) in the Electron app, preventing users from selecting and copying partial text from chat messages. Users can only copy entire messages using the hover copy button.

### Solution
Re-enable text selection specifically for message content areas while keeping it disabled for other UI elements to maintain the native app feel. The browser's built-in copy functionality (Ctrl+C and context menu) will work automatically once selection is enabled.

## Files to Modify

### 1. `covenantrix-desktop/src/styles/globals.css`
**Changes:**
- Add a new CSS utility class `.selectable-text` or similar that overrides the global `user-select: none` behavior
- Apply `user-select: text` and `-webkit-user-select: text` to allow text selection
- Optionally add `-webkit-user-drag: none` to prevent accidental dragging while selecting

### 2. `covenantrix-desktop/src/features/chat/Message.tsx`
**Changes:**

  - Line 69: User message div with `whitespace-pre-wrap`
  - Line 77-86: ReactMarkdown component wrapper for assistant messages
  - Line 67: Error message div (if text selection should be enabled for errors)
- Optionally apply to source citations (lines 90-107) if sources should be selectable
- Ensure the copy button (lines 48-64) remains functional and doesn't interfere with text selection

### 3. `covenantrix-desktop/src/styles/markdown.css` (Optional)
**Changes:**
- Verify that markdown elements (code blocks, tables, lists, etc.) properly support text selection
- Add any necessary overrides if specific markdown elements have selection disabled

## Implementation Notes

### Text Selection Behavior
- Text selection will work automatically once CSS is updated - no JavaScript event handlers needed
- Ctrl+C copy functionality is provided by the browser/Electron automatically
- Right-click context menu is provided by the browser/Electron automatically
- Keep the existing "copy entire message" button for quick full-message copying

### Compatibility Considerations
- Ensure selection works with RTL (right-to-left) text (already supported via `dir` attribute on line 44)
- Ensure selection works during message streaming
- Test selection across both light and dark themes
- Verify that selection highlighting is visible in both theme modes

### Areas NOT to Make Selectable
- Keep text selection disabled for:
  - Navigation elements
  - Buttons and controls
  - Sidebars and headers
  - Other UI chrome elements
